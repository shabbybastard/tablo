# Changelog

Все заметные изменения проекта `tablo`.

## [1.0.6] — 2026-11-27

- Верхняя панель: шестерёнка настроек справа, версия сразу после `tablo`;
  на подэкранах слева домик (на главную) и стрелка назад.
- Дашборд: часы на всю ширину, без Wi-Fi и OTA; погода снизу слева, справа
  карточка очистителя; заметка перенесена в нижнюю строку карточки часов.
- Настройки: видимые вкладки «Основные», «Локальные», «Устройство»,
  «Внешние»; крупные заголовки «Локальные настройки» и «Устройство и сеть».
- Экран «Устройство и сеть»: IP, качество Wi-Fi, CPU, RAM, Flash
  (занято/всего), аптайм, проверка OTA и перезагрузка.
- Убраны отдельные заголовки «Система»/«Экран и сеть»; увеличены отступы,
  исправлена синхронизация переключателей погоды и ночного режима.
- Переходы экранов без slide/fade — на RGB-панели анимация давала двойную
  отрисовку.
- Служебные клавиши Wi-Fi-клавиатуры используют Montserrat (backspace,
  enter, стрелки больше не рисуются как `[]`).
- Внешние данные: очиститель Xiaomi по локальному miIO (UDP 54321) — IP и
  токен во вкладке «Внешние» и в `/config`; PM2.5, температура, влажность,
  фильтр и режим на дашборде, опрос раз в 5 минут с backoff. Поддержаны
  MIoT-модели 3/3H/3C/4/4 Pro/4 Lite/Smartmi и старые 2/2S/Pro.
- LVGL heap увеличен до 192 КБ в PSRAM под новые экраны.
- Включает исправления 1.0.5: LVGL heap в PSRAM, NTP без частых
  перезапусков, диагностические логи IP/DNS/heap.

## [1.0.5] — 2026-11-26

- Убрано отображение питания: на плате нет датчиков V/A, код внешнего INA219
  удалён.
- Верхняя панель: шестерёнка настроек слева, убраны Wi-Fi и питание.
- NTP запускается один раз на подключение; повтор — только при статусе
  `RESET`, с логами `net: wifi up ip=...`, `ntp: waiting/restart` и
  `heap: free=...`.
- LVGL heap перенесён в PSRAM, draw buffer уменьшен до 16 строк: внутренняя
  RAM освобождена для Wi-Fi, TLS и веб-сервера.
- Погодные иконки и три формата даты сохранены.

## [1.0.4] — 2026-11-26

- microSD: тихая CMD0-проверка и backoff, нет спама `GO_IDLE_STATE failed`
  при пустом слоте.
- HTTPS: корректное чтение chunked-ответов (погода Open-Meteo), диагностика
  TLS-ошибок.
- OTA: ретраи с backoff, повторный NTP при потере времени, пинги работают до
  синхронизации часов.
- Дата: символ `·` добавлен в шрифты, три формата отображения.
- Погода: иконки по коду WMO и понятный статус при ошибке.
- Локальные настройки на экране «Экран и сеть»: часовой пояс, погода,
  формат даты и Wi-Fi (скан и ввод пароля на устройстве).
- NVS: миграция blob v1 → v2 с сохранением прежних настроек.

## [1.0.3] — 2026-11-26

- Веб-прошивальщик на GitHub Pages: ESP Web Tools (Apache-2.0), прошивка
  по USB из Chrome, Edge или Opera.
- `flasher.json` использует уже опубликованный `firmware.bin` и три
  boot-образа, отдельный `factory.bin` не нужен.
- OTA-манифест `manifest.json` не изменился.

## [1.0.2] — 2026-11-26

Первый публичный выпуск.

- Дашборд 480×480: часы, дата, погода, AQI, пинги GW/VPS/DNS, заметка.
- Первоначальная настройка: Wi-Fi captive portal или конфиг на microSD.
- microSD с горячей заменой: `tablo-config.json`, шаблон
  `tablo-config.example.json`, проверка и сохранение в NVS.
- OTA через GitHub Pages: manifest, SHA-256, два OTA-слота.
- Rescue mode после трёх неудачных стартов.
- Расписание экрана: вечер/ночь/день по локальному времени, отдельная
  вечерняя и ночная палитра с приглушённой подсветкой.
- Верхняя панель: меню настроек, Wi-Fi и версия; версия подсвечивается
  красным жирным шрифтом при доступном обновлении.
- Удалены интеграции MikroTik и GitHub API из первой версии.
- Версия берётся из `VERSION`; CI собирает прошивку той же версии,
  публикует её на GitHub Pages и создаёт GitHub Release с файлом
  `firmware.bin`.
