# Конфиг на microSD

Плата умеет настраиваться без captive portal: достаточно вставить microSD
(FAT32) с файлом `tablo-config.json` в корне карты.

## Имена файлов

| Файл | Назначение |
|---|---|
| `tablo-config.json` | основной конфиг; плата только читает его и никогда не перезаписывает |
| `tablo-config.example.json` | шаблон с пустыми значениями; плата создаёт его один раз, если основного файла нет |

Шаблон не применяется автоматически. Заполните его на компьютере,
переименуйте в `tablo-config.json` и вставьте карту обратно.

## Первый запуск

1. Включите плату без настроек.
2. На экране выберите **«Конфиг с microSD»**.
3. Вставьте карту. Если `tablo-config.json` нет, плата запишет
   `tablo-config.example.json`.
4. Извлеките карту, заполните шаблон, переименуйте его в `tablo-config.json`.
5. Вставьте карту обратно — плата проверит файл, сохранит настройки в NVS и
   перезагрузится.

Карту можно вставлять и извлекать на горячую, без выключения платы. Если
файл невалиден, настройки в NVS не меняются; исправьте файл, извлеките и
вставьте карту снова.

Для повторной проверки первого запуска на уже настроенной плате сотрите NVS:
`pio run -e esp32s3 -t erase` (стирает всю flash, включая NVS).

## Импорт на работающей плате

Вставьте карту с новым `tablo-config.json`. На экране появится запрос
«Применить и перезагрузить?». После применения хэш файла запоминается в NVS,
поэтому повторная вставка того же файла не вызывает лишних вопросов. Чтобы
применить его снова, измените файл (например, добавьте пробел) или измените
настройки на карте.

## Схема

Если `config_version` указан — он должен быть `1`; если поля нет, оно
считается равным `1`. Неизвестные ключи игнорируются. Файл
**полностью заменяет** настройки: отсутствующий ключ = значение по умолчанию,
пустая строка = пустое значение. Все строки в UTF-8, без управляющих
символов.

| Ключ | Тип | Обязателен | Примечание |
|---|---|---|---|
| `config_version` | integer | нет | только `1` |
| `wifi_ssid` | string | да | до 32 байт |
| `wifi_password` | string | нет | до 64 байт; пусто — открытая сеть |
| `admin_user` | string | да | до 31 байта |
| `admin_password` | string | да | 8–63 байта, не `change-me` |
| `timezone` | string | нет | POSIX TZ, по умолчанию `MSK-3` |
| `weather_lat` | string | нет | число −90…90; вместе с `weather_lon` |
| `weather_lon` | string | нет | число −180…180; вместе с `weather_lat` |
| `ping_gw` | string | нет | хост или IP |
| `ping_vps` | string | нет | хост или IP |
| `ping_dns` | string | нет | хост или IP |
| `ota_manifest_url` | string | нет | только `https://`; пусто — OTA выключен |
| `note` | string | нет | до 95 байт |
| `brightness` | integer | нет | 10…100 |
| `night_mode` | bool | нет | ручной ночной режим |
| `auto_ota` | bool | нет | |
| `night_schedule_enabled` | bool | нет | авторежим вечер/ночь/день |
| `evening_start` | string | нет | `HH:MM`, по умолчанию `18:00` |
| `night_start` | string | нет | `HH:MM`, по умолчанию `23:00` |
| `day_start` | string | нет | `HH:MM`, по умолчанию `07:00` |

Максимальный размер файла — 8 КиБ. Поддерживаются UTF-8 BOM и переводы строк
CRLF. JSON-комментарии не поддерживаются. Для расписания требуется порядок
`day_start < evening_start < night_start`; вечер и ночь используют 60% и 25%
дневной яркости.

## Безопасность

В `tablo-config.json` пароли хранятся в открытом виде. Не оставляйте карту с
реальными паролями в устройстве после импорта и не публикуйте файл.
`tablo-config.example.json` содержит только пустые значения и не включает
`secrets.h` из прошивки.
