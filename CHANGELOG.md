# Changelog

Все заметные изменения проекта `tablo`.

## [1.0.2] — 2026-11-26

Первый публичный выпуск.

- Дашборд 480×480: часы, дата, погода, AQI, пинги GW/VPS/DNS, заметка.
- Первоначальная настройка: Wi-Fi captive portal или конфиг на microSD.
- microSD с горячей заменой: `tablo-config.json`, шаблон
  `tablo-config.example.json`, проверка и сохранение в NVS.
- OTA через GitHub Pages: manifest, SHA-256, два OTA-слота.
- Rescue mode после трёх неудачных стартов.
- Расписание экрана: вечер/ночь/день по локальному времени, отдельная
  вечерняя и ночная палитра с приглушённой подсветкой.
- Верхняя панель: меню настроек, Wi-Fi и версия; версия подсвечивается
  красным жирным шрифтом при доступном обновлении.
- Удалены интеграции MikroTik и GitHub API из первой версии.
- Версия берётся из `VERSION`; CI собирает прошивку той же версии,
  публикует её на GitHub Pages и создаёт GitHub Release с файлом
  `firmware.bin`.
